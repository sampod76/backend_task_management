# 🔹 process(eventData)

## 🧠 Purpose

`process()` হলো **Rule Engine এর main entry point**

👉 যখন কোনো event trigger হয়, তখন এই method call করা হয়
👉 এই method পুরো automation flow control করে

---

## ⚙️ Method Signature

```ts
async process(eventData: AutomationEvent): Promise<void>
```

---

## 📥 Input (eventData)

👉 `eventData` হলো trigger হওয়া event object

### Example:

```ts
{
  eventType: "USER_CREATED",
  user: {
    id: "u1",
    name: "Rahim",
    role: "student",
    email: "rahim@example.com"
  }
}
```

---

## 🔁 Internal Flow (Step by Step)

### ✅ Step 1: Active Rules Fetch

```ts
const rules = await repo.findActiveByEvent(eventData.eventType);
```

👉 DB থেকে সব active rules আনা হয়
👉 filter condition:

```sql
WHERE eventType = eventData.eventType
AND isActive = true
```

---

### ✅ Step 2: Condition Matching

```ts
const matchedRules = rules.filter((rule) => matchConditions(rule, eventData));
```

👉 প্রতিটি rule check করা হয়
👉 `matchConditions()` decide করে rule run হবে কিনা

---

### ✅ Step 3: Logging

```ts
logger.log(`Matched rules=${matchedRules.length}`);
```

👉 কতগুলো rule match করেছে সেটা log করা হয়

---

### ✅ Step 4: Execute Rules

```ts
for (const rule of matchedRules) {
  await executeRule(rule, eventData);
}
```

👉 প্রতিটি matched rule execute করা হয়
👉 sequential execution (একটার পর একটা)

---

## 🔥 Full Example (Real Scenario)

---

### 🧾 Rules in DB

#### Rule 1:

```json
{
  "eventType": "USER_CREATED",
  "conditions": {
    "user.role": "student"
  },
  "actions": [{ "type": "SEND_EMAIL" }]
}
```

---

#### Rule 2:

```json
{
  "eventType": "USER_CREATED",
  "conditions": {
    "user.role": "admin"
  },
  "actions": [{ "type": "SEND_NOTIFICATION" }]
}
```

---

### 📥 Event আসে

```ts
process({
  eventType: 'USER_CREATED',
  user: {
    name: 'Rahim',
    role: 'student',
    email: 'rahim@example.com',
  },
});
```

---

### ⚙️ Execution Flow

1. DB থেকে 2টা rule আসলো

2. matchConditions check:
   - Rule 1 → ✅ match (student)
   - Rule 2 → ❌ match না (admin না)

3. matchedRules = [Rule 1]

4. executeRule() call হলো

---

### 🎯 Final Result

👉 Rahim কে email পাঠানো হবে
👉 notification যাবে না

---

## ⚠️ Important Notes

### 🔸 1. No Conditions Case

```ts
if (!conditions) return true;
```

👉 condition না থাকলে rule **সবসময় run হবে**

---

### 🔸 2. Sequential Execution

```ts
for (...) {
  await executeRule(...)
}
```

👉 parallel না, একটার পর একটা execute হয়

---

### 🔸 3. No Return Value

```ts
Promise<void>;
```

👉 এই method return কিছু করে না
👉 pure side-effect (email, notification, webhook)

---

### 🔸 4. Rule ভিত্তিক Execution

👉 সব rule run হবে না
👉 শুধু matched rule run হবে

---

## 🧠 Mental Model

👉 তুমি এভাবে চিন্তা করতে পারো:

```
Event → Rules Load → Condition Check → Matched Rules → Execute Actions
```
