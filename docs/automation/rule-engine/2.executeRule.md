# 🔹 executeRule(rule, eventData)

## 🧠 Purpose

`executeRule()` এর কাজ হলো:

👉 **একটা matched rule এর সব actions execute করা**

---

## ⚙️ Method Signature

```ts
private async executeRule(rule: AutomationRule, eventData: AutomationEvent)
```

---

## 📥 Input

### 1. rule (DB থেকে আসা)

```json
{
  "actions": [
    {
      "type": "SEND_EMAIL",
      "to": "{{user.email}}",
      "subject": "Welcome {{user.name}}",
      "body": "Welcome {{user.email}}"
    }
  ]
}
```

---

### 2. eventData (runtime data)

```ts
{
  user: {
    name: "Rahim",
    email: "rahim@example.com"
  }
}
```

---

## 🔁 Internal Flow (Step by Step)

---

### ✅ Step 1: Actions Parse

```ts
const runtimeRule = mapRuleRowsToRuntimeRule(rule);
const actions = runtimeRule.actions;
```

👉 DB থেকে আসা JSON → array এ convert করা হয়

---

### ✅ Step 2: Loop Actions

```ts
for (const action of actions)
```

👉 একাধিক action থাকলে একটার পর একটা execute হবে

---

### ✅ Step 3: Resolve Template

```ts
const resolvedAction = resolveTemplate(action, eventData);
```

👉 `{{ }}` placeholder replace হয়

---

### 💡 Example

#### Before:

```json
{
  "to": "{{user.email}}",
  "subject": "Hello {{user.name}}"
}
```

#### After:

```json
{
  "to": "rahim@example.com",
  "subject": "Hello Rahim"
}
```

---

### ✅ Step 4: Execute Based on Type

```ts
switch (resolvedAction.type)
```

---

## 🔥 Supported Action Types

---

### 📧 1. SEND_EMAIL

```ts
await emailActionService.send(resolvedAction, eventData);
```

👉 email পাঠানো হয়

---

### 🔔 2. SEND_NOTIFICATION

```ts
await notificationActionService.send(resolvedAction, eventData);
```

👉 notification পাঠানো হয়

---

### 🌐 3. SEND_WEBHOOK

```ts
await executeWebhook(action);
```

👉 URL, headers, payload, method, timeout সব template resolve হয়ে request পাঠানো হয়

---

### ❗ Default (Unknown Action)

```ts
logger.warn('Unknown action type');
```

👉 ভুল type হলে warning দেয়

---

## 🔥 Full Example (Real Scenario)

---

### 🧾 Rule

```json
{
  "actions": [
    {
      "type": "SEND_EMAIL",
      "to": "{{user.email}}",
      "subject": "Welcome {{user.name}}"
    },
    {
      "type": "SEND_NOTIFICATION",
      "title": "New user {{user.name}}"
    }
  ]
}
```

---

### 📥 Event

```ts
{
  user: {
    name: "Rahim",
    email: "rahim@example.com"
  }
}
```

---

### ⚙️ Execution Flow

1. action[0] → SEND_EMAIL
   - template resolve
   - email send

2. action[1] → SEND_NOTIFICATION
   - template resolve
   - notification send

---

### 🎯 Final Result

👉 Rahim email পাবে
👉 notification trigger হবে

---

## ⚠️ Important Notes

---

### 🔸 1. Sequential Execution

```ts
for (...) {
  await ...
}
```

👉 action গুলো parallel না
👉 একটার পর একটা run হয়

---

### 🔸 2. Template First, Then Execute

👉 সব action আগে resolve হয়
👉 তারপর execute হয়

---

### 🔸 3. Unknown Action Safe

👉 crash না করে warning দেয়

---

### 🔸 4. Strongly Typed Flow

👉 `AutomationActionType` দিয়ে control করা হয়

---

## 🧠 Mental Model

```text
Rule → Actions → Loop → Resolve → Execute
```
