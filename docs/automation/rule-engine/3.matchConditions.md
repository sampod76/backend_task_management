# 🔹 matchConditions() + Condition Helpers

---

## 🧠 Overview

এই section-এ ৩টা core function আছে:

- `matchConditions()` → main matcher (brain)
- `isExistsCondition()` → exists condition detect
- `isComparisonCondition()` → comparison detect
- `matchComparison()` → comparison evaluate

👉 সহজভাবে:

**Rule conditions → eventData এর সাথে match হচ্ছে কিনা check করে**

---

# 🔥 1. matchConditions(rule, eventData)

## 📌 Purpose

👉 এটা পুরো Automation Rule Engine এর **core matching function**

👉 কাজ:

- rule.conditions → eventData এর সাথে compare করা
- match হলে → `true`
- না হলে → `false`

---

## 📤 Return

| Value | Meaning            |
| ----- | ------------------ |
| true  | সব condition match |
| false | কোনো একটা fail     |

---

## ⚙️ Internal Flow (Step by Step)

---

### ✅ Step 1: Conditions Load

```ts
const runtimeRule = mapRuleRowsToRuntimeRule(rule);
const conditions = runtimeRule.conditions;
```

---

### ✅ Step 2: No Condition Case

```ts
if (!conditions || empty) return true;
```

👉 condition না থাকলে → rule always run

---

### ✅ Step 3: Loop Conditions

```ts
for (const [path, expectedValue])
```

👉 example:

```json
{
  "user.age": { "gt": 18 }
}
```

---

### ✅ Step 4: Get Actual Value

```ts
const actualValue = getByPath(eventData, path);
```

👉 nested support:

```ts
'user.profile.age';
```

---

### ✅ Step 5: Condition Type Check

---

## 🧠 Supported Condition Types

---

### 🔹 1. Exists Condition

```ts
if (isExistsCondition(expectedValue))
```

---

#### Example:

```json
{
  "user.phone": { "exists": true }
}
```

---

#### Logic:

```ts
exists = actualValue !== undefined && !== null
```

---

#### Result:

| Condition     | Result             |
| ------------- | ------------------ |
| exists: true  | field থাকতে হবে    |
| exists: false | field থাকা যাবে না |

---

### 🔹 2. Comparison Condition

```ts
if (isComparisonCondition(expectedValue))
```

---

#### Example:

```json
{
  "user.age": { "gt": 18 }
}
```

---

#### Supported Operators:

| Operator | Meaning |
| -------- | ------- |
| gt       | >       |
| gte      | ≥       |
| lt       | <       |
| lte      | ≤       |
| ne       | !=      |
| eq       | ===     |

---

#### Example: Range

```json
{
  "user.age": { "gte": 18, "lte": 60 }
}
```

---

👉 evaluation:

```ts
18 <= age <= 60;
```

---

### 🔹 3. Direct Equality

```ts
if (actualValue !== expectedValue)
```

---

#### Example:

```json
{
  "user.role": "admin"
}
```

---

👉 meaning:

```ts
event.user.role === 'admin';
```

---

## ⚠️ Important Behavior

---

### 🔸 AND Logic

```ts
if (any condition fails) return false
```

👉 সব condition match করতে হবে

---

### 🔸 Early Exit

👉 fail হলেই loop stop হয়ে যায়

---

### 🔸 Strict Equality

```ts
===
```

# 🔧 2. isExistsCondition(value)

## 📌 Purpose

👉 check করে value টি exists condition কিনা

---

## ⚙️ Logic

```ts
typeof value === 'object' && value !== null && 'exists' in value;
```

---

## 💡 Example

```ts
isExistsCondition({ exists: true }); // true
isExistsCondition({ exists: false }); // true
isExistsCondition({ value: 10 }); // false
```

---

## 🧠 Meaning

| Condition     | Meaning            |
| ------------- | ------------------ |
| exists: true  | value থাকতে হবে    |
| exists: false | value থাকা যাবে না |

---

```ts
/**
   * Checks whether a rule's conditions match the given eventData.
   *
   * @param rule/actions in object - AutomationRule (DB থেকে আসা rule)
   * @param eventData - AutomationEvent (trigger হওয়া event data)
   *
   * @returns boolean
   * - true  → সব condition match করেছে (rule execute হবে)
   * - false → কোন condition match করে নাই (rule skip হবে)
   *
   * @example
   * // type 1: direct equality
   * conditions = { "name.fastName": "abc" }
   * eventData = { name: { fastName: "abc" } }
   * 👉 result: true
   *
   * @example
   * // type 2: exists condition
   * conditions = { "name.fastName": { exists: true } }
   * 👉 field থাকলে match
   *
   * @example
   * // exists false
   * conditions = { "name.middleName": { exists: false } }
   * 👉 field না থাকলে match
   *
   * @example
   * // type 3: comparison (NEW)
   * conditions = { "user.age": { gt: 18 } }
   * 👉 user.age > 18 হলে match
   *
   * @example
   * // range condition
   * conditions = { "user.age": { gte: 18, lte: 60 } }
   * 👉 18 ≤ age ≤ 60
   *
   * @description
   * এই function টা Automation Rule Engine এর core logic।
   * এটি rule এর conditions গুলো eventData এর সাথে match করে কিনা check করে।
   *
   * Supported condition types:
   *
   * 1. Direct value match:
   *    { "field.path": value }
   *    👉 eventData এর value === expected value
   *
   * 2. Exists condition:
   *    { "field.path": { exists: true/false } }
   *    👉 field আছে বা নাই check করে
   *
   * 3. Comparison operators:
   *    { "field.path": { gt, gte, lt, lte, ne, eq } }
   *
 
   *
   * Process:
   * 1. যদি conditions না থাকে → true (rule সব সময় run হবে)
   * 2. প্রতিটি condition loop করে evaluate করা হয়
   * 3. getByPath() দিয়ে nested value বের করা হয়
   * 4. condition type অনুযায়ী match করা হয়:
   *    - exists → existence check
   *    - comparison → numeric / value compare
   *    - default → strict equality
   *
   * ⚠️ Notes:
   * - সব condition AND logic এ কাজ করে
   * - strict equality (===) use করা হয়
   * - nested path support করে (e.g. "user.profile.email")
   *
   * 💡 Use Cases:
   * - dynamic rule matching
   * - event-driven automation system
   * - no-code backend logic execution
   */
```

# 🔧 4. matchComparison(actualValue, condition)

## 📌 Purpose

👉 comparison condition evaluate করা

---

## ⚙️ Core Logic

---

### ❌ Null/Undefined Case

```ts
if (actualValue === null || undefined) return false;
```

---

### 🔹 gt

```ts
Number(actualValue) > condition.gt;
```

---

### 🔹 gte

```ts
>=
```

---

### 🔹 lt

```ts
<
```

---

### 🔹 lte

```ts
<=
```

---

### 🔹 ne

```ts
actualValue !== condition.ne;
```

---

### 🔹 eq

```ts
actualValue === condition.eq;
```

---

## 💡 Example

---

### Input

```json
{
  "user.age": { "gte": 18, "lte": 60 }
}
```

---

### Event

```ts
{
  user: {
    age: 25;
  }
}
```

---

### Result

```ts
true;
```

---

---

## ⚠️ Important Notes

---

### 🔸 Number Casting

```ts
Number(actualValue);
```

👉 string number হলেও কাজ করবে

---

### 🔸 Multiple Condition Support

```ts
{ gte: 18, lte: 60 }
```

👉 একসাথে multiple check

# 🧠 Full Mental Model

```text
Loop conditions →
  get actual value →
    check type →
      exists → compare existence
      comparison → numeric compare
      default → strict equality
```
