# 🔹 resolveTemplate(input, eventData)

---

## 🧠 Purpose

👉 action data এর ভিতরে থাকা `{{ }}` template dynamic value দিয়ে replace করা

👉 এটা Automation Rule Engine এর **template resolver**

---

## ⚙️ Method Signature

```ts
resolveTemplate(input: unknown, eventData: AutomationEvent): unknown
```

---

## 📥 Parameters

### 🔸 input

- যেকোনো data (string | object | array | primitive)
- সাধারণত `actions` config থেকে আসে

### 🔸 eventData

- event object যেখান থেকে dynamic value নেওয়া হবে

---

## 📤 Return

👉 processed value যেখানে সব template (`{{ }}`) replace হয়ে যাবে

---

# 🧠 Supported Features

---

## ✅ 1. String Template

```ts
input = 'Hello {{user.name}}';
eventData = { user: { name: 'Rahim' } };
```

👉 Result:

```ts
'Hello Rahim';
```

---

## ✅ 2. Object Template

```ts
input = {
  to: '{{user.email}}',
  subject: 'Welcome {{user.name}}',
  body: 'Welcome {{user.email}}',
};
```

👉 Result:

```ts
{
  to: "rahim@example.com",
  subject: "Welcome Rahim",
  body: "Welcome rahim@example.com"
}
```

---

## ✅ 3. Array Template

```ts
input = ['{{user.name}}', '{{user.role}}'];
```

👉 Result:

```ts
['Rahim', 'admin'];
```

---

## ✅ 4. Nested Object Support

👉 deeply nested structure recursively resolve হয়

```ts
input = {
  meta: {
    user: {
      email: '{{user.email}}',
    },
  },
};
```

---

## ✅ 5. Dot Notation Path

```ts
'{{user.profile.email}}';
```

👉 internally:

```ts
getByPath(eventData, 'user.profile.email');
```

---

# ⚙️ Internal Process (Step by Step)

---

### 🔹 Step 1: Detect Template

👉 regex ব্যবহার করে `{{ }}` detect করা হয়

---

### 🔹 Step 2: Extract Path

```ts
{{ user.name }} → "user.name"
```

---

### 🔹 Step 3: Get Value

👉 `getByPath()` দিয়ে eventData থেকে value আনা হয়

---

### 🔹 Step 4: Convert Value

| Type           | Conversion        |
| -------------- | ----------------- |
| object         | JSON.stringify    |
| string/number  | String()          |
| null/undefined | "" (empty string) |

---

### 🔹 Step 5: Recursive Resolve

- array হলে → map()
- object হলে → key-value loop

---

# ⚠️ Important Notes

---

### 🔸 Unknown Path

```ts
'{{user.unknown}}';
```

👉 Result:

```ts
'';
```

---

### 🔸 Null / Undefined

👉 empty string return করে

---

### 🔸 Object Value

👉 stringify হয়ে যায়

```ts
{ a: 1 } → '{"a":1}'
```

---

### 🔸 Circular Object (Future Risk)

👉 JSON.stringify error হতে পারে
