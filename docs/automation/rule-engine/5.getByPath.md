# 📘 getByPath — Function Documentation

---

## 🧠 Overview

`getByPath()` হলো একটি utility function যা **deep nested object থেকে dot notation ব্যবহার করে value বের করে**।

👉 সহজভাবে:

> `"user.profile.email"` → object এর ভিতর থেকে value extract করে

---

## 📌 Purpose

- nested object safe ভাবে access করা
- undefined error avoid করা
- dynamic path দিয়ে data retrieve করা

---

## ⚙️ Function Signature

```ts
getByPath(source: unknown, path: string): unknown //source-> eventData //path->
```

---

## 📥 Parameters

### 🔹 source

- যেকোনো object (nested structure হতে পারে)
- type: `unknown`

---

### 🔹 path

- dot notation string
- example:

  ```ts
  'name.fastName.id';
  ```

---

## 📤 Return

| Case      | Result       |
| --------- | ------------ |
| value আছে | actual value |
| value নাই | undefined    |

---

## 💡 Examples

---

### ✅ Example 1: Valid Path

```ts
const obj = {
  name: {
    fastName: {
      id: 1,
    },
  },
};

const result = getByPath(obj, 'name.fastName.id');
console.log(result); // 👉 1
```

---

### ❌ Example 2: Invalid Path

```ts
const result = getByPath(obj, 'name.lastName');
console.log(result); // 👉 undefined
```

---

### ✅ Example 3: Deep Nested

```ts
const obj = {
  user: {
    profile: {
      email: 'rahim@example.com',
    },
  },
};

getByPath(obj, 'user.profile.email'); // "rahim@example.com"
```

---

## ⚙️ Internal Logic

Function টি step-by-step নিচের কাজগুলো করে:

---

### 🔹 Step 1: Path Split

```ts
path.split('.');
```

👉 `"name.fastName.id"` → `["name", "fastName", "id"]`

---

### 🔹 Step 2: Reduce Traverse

```ts
.reduce(...)
```

👉 প্রতিটি key ধরে object traverse করে

---

### 🔹 Step 3: Safe Access

```ts
if (current && typeof current === 'object' && key in current)
```

👉 check করে:

- current object কিনা
- key exist করে কিনা

---

### 🔹 Step 4: Return Value

- value পেলে → return
- না পেলে → `undefined`

---

## 🧠 Mental Model

```text
path.split → loop keys →
  check exists →
    go deeper →
      return final value
```

## ⚠️ Important Notes

---

### 🔸 1. Safe Access

👉 error throw করে না

```ts
getByPath(undefined, 'a.b.c'); // ❌ crash না করে safe থাকে
```

---

### 🔸 2. Nested Support

👉 unlimited depth support করে

---

### 🔸 3. Dynamic Path

👉 runtime path ব্যবহার করা যায়

```ts
const key = 'user.profile.email';
getByPath(obj, key);
```

### 🔸 4. Undefined Handling

👉 missing field হলে:

```ts
undefined;
```
