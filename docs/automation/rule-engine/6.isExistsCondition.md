## 🔹 4. isExistsCondition(value)

### 📌 Purpose

👉 check করে value টি exists condition কিনা

---

### ⚙️ Logic

- value object কিনা
- null না কিনা
- `"exists"` property আছে কিনা

---

### 💡 Example

```ts
isExistsCondition({ exists: true }); // true
isExistsCondition({ exists: false }); // true
isExistsCondition({ value: 10 }); // false
isExistsCondition(null); // false
```

---

### 🧠 Meaning

```ts
{ exists: true }  → field থাকা লাগবে
{ exists: false } → field থাকা যাবে না
```
