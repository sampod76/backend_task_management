## 🔹 6. matchComparison(actualValue, condition)

### 📌 Purpose

👉 comparison condition evaluate করা

---

### ⚙️ Internal Logic

- value undefined/null হলে → false
- Number() দিয়ে cast করে compare করা হয়

---

### 💡 Example

```ts
{ gt: 18 } → value > 18
{ gte: 18, lte: 60 } → range check
```

---

### ⚠️ Notes

- strict comparison follow করে
- multiple operator একসাথে কাজ করতে পারে
